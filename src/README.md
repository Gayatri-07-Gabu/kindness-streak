
# Kindness Streak 🌱

A simple mobile app that helps you build a daily habit of small acts of kindness. Log one kind act each day, track your streak, and get inspired with random kindness ideas when you're stuck.

## Features

- **Daily kindness logging** — mark that you did a kind thing today
- **Streak counter** — see how many days you've kept it up
- **Idea generator** — get a random suggestion when you need inspiration
- **30-day streak calendar** — a visual grid showing your recent activity
- **Local storage** — your data stays on your device, no account needed

## Tech Stack

- [React Native](https://reactnative.dev/)
- [Expo](https://expo.dev/) (Expo Router)
- [AsyncStorage](https://github.com/react-native-async-storage/async-storage) for local data persistence
